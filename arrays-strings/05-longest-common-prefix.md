## Problem: Longest Common Prefix (Easy)

**Link:** https://leetcode.com/problems/longest-common-prefix/

### Approach

Compare the characters of the first string with the corresponding characters of all other strings.
Stop when a character differs or when the end of any string is reached.

### Complexity

- Time: O(n × m)
- Space: O(1)
